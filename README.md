# infOS Market

infOS 官方维护的扩展与内容市场目录，归属 **Astrmira / 幻梦星芒科技**。

这里用于收录内容的介绍、作者、版本、兼容范围与下载来源。插件源码和发行包可以由各自作者维护；被收录不要求把源码迁入本组织。

**当前处于仓库初始化阶段，尚无正式条目，infOS 客户端也尚未接入此市场。** 目录格式、安装流程与 Steam 创意工坊关联方式将在对应功能设计时确定。

## 内容范围

| 分类 | 内容示例 |
| --- | --- |
| 插件与工具 | 扩展能力、工具包、应用集成 |
| Skill | 按需加载的任务知识与使用指导 |
| 角色包 | 角色定义、头像、立绘及关联资源 |
| 桌宠资源 | 模型、纹理、动作与动画资源 |
| 外观与提示词 | 主题、提示词预设及其他可分发内容 |

各类内容的安装与数据归属遵循 infOS 主项目架构，具体目录约定见 [catalog](catalog/README.md)。

## 参与维护

- 希望收录内容：先阅读 [贡献说明](CONTRIBUTING.md)，再提交 Issue 或 PR。
- 市场设计与问题反馈：使用本仓库的 [Issues](https://github.com/Astrmira/infOS-Market/issues)。
- infOS 本体问题：请前往 [infOS 主项目](https://github.com/YoKONCy/infOS)。
